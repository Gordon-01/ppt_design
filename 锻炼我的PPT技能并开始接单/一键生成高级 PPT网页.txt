## PPT 网⻚特殊要求
### ⻚面结构设计
1. ** 全屏宽屏展示 **
- 每一⻚占满整个屏幕( 100vh )
- 宽屏比例优化( 16:9 或 16:10 )
- 白色背景为主色调
- 内容居中对⻬
2. ** 严格布局约束 **
- ** 背景约束 **:除首⻚和最后一⻚外,所有正文⻚面必须使用纯白色背景( #FFFFFF ),严格禁
止使用渐变背景或其他背景效果
- ** 尺寸统一 **:每一⻚的宽度和高度必须完全统一( 100vw × 100vh )
- ** 标题定位 **:每一⻚的标题字体大小必须统一(建议: h1 为 36px ),且与⻚面顶部的距离必
须保持一致(固定为 100px )
- ** 内容区域限定 **:每⻚的主要内容必须固定在统一的区域内,内容区域边界明确限定(固定
为:距离⻚面左右边缘 15% ,距离顶部 180px ,距离底部 100px )
- ** 内容溢出处理 **:当内容无法在一⻚内完全展示时,必须创建新的⻚面,严格禁止破坏统一的
布局结构
3. ** ⻚面导航系统 **
- 垂直滚动切换⻚面
- 平滑滚动过渡效果
- 无需显式滚动按钮
- 支持键盘导航(上下箭头、 Page Up/Down )
- 支持鼠标滚轮导航
4. ** ⻚面指示器 **
- 右侧或底部⻚面指示点
- 当前⻚面高亮显示
- 点击可直接跳转到指定⻚面
- 显示总⻚数和当前⻚数

function safeSlideNavigation(targetSlide) {
try {
if (targetSlide < 0 || targetSlide >= totalSlides) {
console.warn(`Invalid slide index: ${targetSlide}`);
return false;
}
if (isScrolling) {
return false; // 防止快速连续滚动
}
navigateToSlide(targetSlide);
return true;
} catch (error) {

return false;
}
}
