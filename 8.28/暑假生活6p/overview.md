# 我的暑假生活 PPT 制作概述

## 交付物
- `我的暑假生活.pptx`：共 6 页，16:9 宽屏，适合小学生开学班会 3-5 分钟演讲。
- `preview_grid.png`：6 页版式预览图。
- `assets/`：原始配图。
- `assets2/`：统一比例裁剪后的配图（供 `build2.py` 复用）。
- `build2.py`：PPT 生成脚本（含完整版式代码）。

## 页面结构
1. **封面页**：左右分屏，左侧暖色面板放标题、姓名/班级占位符；右侧满幅夏日向日葵实景图。
2. **自律学习**：左侧 4 个卡片式要点，右侧圆角儿童阅读场景大图。
3. **锻炼与新本领**：双卡片并排，上方圆角图片带主题标签，下方 3 条要点。
4. **社会实践**：左侧圆角书店场景大图，右侧 4 个卡片式要点。
5. **快乐旅行**：4 张景点实景小图横向排列（丹霞、莫高窟、长城、兵马俑），下方附旅行感悟。
6. **结尾页**：风景底图 + 居中圆角卡片，总结“知识、勇气、成长”，表达新学期心愿并致谢。

## 设计说明（V2 重制版）
- **统一网格系统**：统一边距、标题区、分隔线、页脚，页面视觉节奏一致。
- **圆角与层次**：所有图片和卡片均使用圆角处理，并加入柔和投影，避免生硬拼接。
- **统一比例裁剪**：图片在放入 PPT 前先按目标画幅（竖版/横版/4:3）居中裁剪，避免拉伸变形。
- **主题色映射**：01 自律学习-天蓝、02 锻炼新本领-珊瑚、03 社会实践-薰衣草、04 快乐旅行-暖黄、结尾-薄荷绿。
- **字体**：Microsoft YaHei，确保在大多数 Windows 电脑上正常显示。
- **图片来源**：Wikimedia Commons 公开图库，已嵌入 PPTX，无需额外素材。

## 工具链安装情况
- `tencent-pptx` 的 `slidep` 工具链未能在当前环境完成安装：npm 在清理缓存临时目录时被安全删除策略拦截（`[safe-delete] 操作失败`）。
- 因此改用 Python + `python-pptx` 直接生成 `.pptx`，并通过严格的版式设计保证视觉效果。

## 使用提示
- 打开 PPT 后，请将封面“姓名：XXX  班级：X年X班”替换为真实信息。
- 如需调整演讲稿、图片或配色，可直接在 PowerPoint/WPS 中编辑，或修改 `build2.py` 后重新生成。
