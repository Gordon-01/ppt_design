## 项目档案 #1：2026财年市场大调研复盘PPT（口味王河南地区，21页）

- 时间：2026-08-28 ~ 08-29
- 模板：红色品牌系（标题红 C00000 / 标题条红 FF0000），页眉 logo+红条，页脚右下品牌块
- 委托演变：先改12-13页 → 加14、11页 → 按3轮客户反馈重做 → 扩展到15-21页 → 全文校对
- 结果：客户认可（"效果可以，没有破坏原有模板和风格，空白处优化得好"）

### 客户反馈迭代史（重要：理解"满意"是怎么来的）

| 轮次 | 我们做了什么 | 客户反馈 | 学到什么 |
|------|-------------|---------|---------|
| 1 | L1修硬伤：去继承蓝描边、照片等高对齐、浅红圆角卡 | "过于简单了……排版显得很空旷。图片页字不多但不空旷" | "简单"≠"少改动"；空旷=缺容器和层级；L1 不够 |
| 2 | 参考图逻辑：白卡+阴影+chevron箭头角标+粗标题 | "图标和样图很像……有点完全在抄的感觉" | 学结构必须换造型；角标改用原文自带的"1.2.3."编号 |
| 3 | 数字块角标版 + 客户指出两处残留空旷（卡右半空白、问题点到建议间的空白带） | 认可 | 卡内改"标题\|竖线\|正文"横向布局消灭半边空白；问题点正文也入卡（模板三角做标记）消灭空白带 |
| 4 | 15-21页复用同一系统（纯文字页、彩色图表页、占位垃圾页） | 前提是"一定保持统一风格"，字号不许局部放大 | 同一构建函数跨页复用是统一性的技术保证 |

### 踩坑实录（现象 → 原因 → 修复 → 沉淀规则）

1. **静默空跑 ×2**
   - 现象：脚本打印"replaced N"，渲染图毫无变化。两次。
   - 原因：`s.shape_type == MSO_SHAPE.CHEVRON` / `== MSO_SHAPE.ROUNDED_RECTANGLE` 永远为假——shape_type 是 MSO_SHAPE_TYPE 枚举，不是图形种类；比较不报错。
   - 修复：用 `spPr/prstGeom@prst` 判断图形（'chevron'/'rect'/'roundRect'）。
   - 沉淀：SKILL.md 反模式 #1；cookbook §3。

2. **异常吞噬导致清理失效**
   - 现象：purge 后旧卡片残影留在页面上（渲染可见被新卡裁掉一半的旧标题）。
   - 原因：清理循环里 try/except 吞掉了枚举属性错误（见坑1），循环空转但整体"成功"。
   - 修复：改签名匹配（geom+fill+是否含文字+id范围），清完 dump 清单核对"removed: N"。
   - 沉淀：反模式 #2；Phase 3 施工纪律第4条。

3. **误删正文**
   - 现象：第12页"问题点"正文整段消失（重建脚本无条件删 paragraphs[1:]）。
   - 修复：从**原始文件**同 id 形状取回原文重写。
   - 沉淀：Phase 3 "先取文再删形"；从原始文件取证是兜底手段。

4. **卡片文字莫名居中**
   - 原因：add_shape 的 text_frame 段落默认居中。
   - 沉淀：所有正文/标题显式 `PP_ALIGN.LEFT`。

5. **第17页卡片文字溢出下边缘**
   - 现象：渲染图上最后一行文字压在卡片底边上。
   - 原因：多段正文卡高度拍脑袋估的。
   - 修复：渲染发现后加高（2.75→3.1），分隔线、正文框同步加高。
   - 沉淀：多段卡高度=行数×0.29+段距+上下padding，且必须渲染复验。

6. **文件锁 ×3**
   - 现象：保存/覆盖报 PermissionError；`~$` 锁文件出现。
   - 原因：用户正开着文件看；同步盘置只读属性。
   - 修复：临时文件 + `mv -f` 重试循环；`chmod +w`。全程不杀 POWERPNT 进程（用户可能开着原始文件）。
   - 沉淀：SKILL.md Phase 4。

7. **渲染验收抓住的全部问题**（没有渲染就会交付出去）
   - 残影（旧卡未删净）、第12页正文丢失、第17页溢出、第一版卡片文字居中。
   - 沉淀："脚本成功"≠"改好了"，渲染+逐页看图是唯一验收。

### 最终验证过的版式参数（13.33×7.5 画布）

| 元素 | 参数 |
|------|------|
| 白卡阴影 | blurRad=90000, dist=25400, dir=5400000, 黑 alpha 12% |
| 角标 | 0.42×0.42 圆角方块 adj 0.22，白字16pt粗体 |
| 横排卡 | 单行 h=0.7-0.86 / 双行 h=1.1-1.35；行距 0.06-0.32 |
| 卡内结构 | 角标+0.2起；标题 x+0.78 宽1.42；竖线 x+2.32；正文 x+2.56 |
| 问题卡 | 三角 0.3×0.34 rot90 @x+0.76；正文 x+1.32 宽9.55，14pt，行距1.25 |
| 内容列 | x=0.45 宽10.74；卡片底缘 ≤7.25；页脚 logo 区(12.03+)禁入 |
| 字号锁 | 卡标题15/正文14/区块标题16，全片一致 |
| 字体 | 微软雅黑（用户机器必有；CJK 用 Regular/Bold，不用 Light） |
